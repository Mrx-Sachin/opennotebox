Note-taking landscape (exploration only)

You pointed at Amphi (useamphi.com): an AI-native student workspace - one canvas for notes, documents, flashcards, calculators, and embedded tutors. Currently iPad beta (desktop/Android waitlist). It is a closed product, not an embeddable API. We do not integrate Amphi itself; we take the product lessons and map them to things OpenNoteBox can own or export into later.

What Amphi does well

  • Single canvas: notes + PDF + AI in one context
  • AI that sees current work (not a separate ChatGPT tab)
  • Flashcards and study flows next to source material
  • Subject-shaped tutors (adaptation)

What OpenNoteBox already has

  • PDF reader + click-to-read TTS
  • Doc-grounded chat with citations
  • Summaries, podcasts, FSRS flashcards
  • Export-to-folder mirror (chat/cards/audio)
  • Reading progress + bookmarks

Real integration targets (later)

  • Obsidian - vault markdown export / folder sync (export already points this way)
  • Logseq / Anytype - block/markdown dump
  • Anki - .apkg from flashcards (higher value than reinventing reviews)
  • Notion - API if users want cloud wiki (optional)
  • Clipboard / selection - bridge to any external note app today

Own product gap (Amphi-shaped, later PRs)

  • In-PDF highlights + notes (schema sketched in HANDOFF_ANNOTATIONS)
  • Notes list in AI panel (no 4th column)
  • “Send selection to chat” / “make flashcard from selection”
  • Markdown export of annotations into export-folder
Decision for this sprint: do not build a notes canvas or Amphi clone. Do structural backend work so the app can support annotations/export cleanly later. Ship PDF auto-copy as the bridge to external note apps (Obsidian, Apple Notes, Amphi if user pastes).

What we are not doing in this pass

  • No Amphi / third-party deep integration (no public API to target for Amphi).
  • No full notes canvas or multi-panel redesign.
  • No rerank/embeddings routing changes without the new timing numbers.
  • No Celery/Redis rewrite, no external vector DB.

Acceptance for this build

  • database.py has no async engine; no import breaks.
  • Alembic migration for composite indexes revises d5b8f21ac640.
  • Chat logs include stage timings like chat.stage rewrite=…ms retrieve=…ms.
  • Chat DB sessions closed before long LLM awaits (router + engine).
  • Summarizer truncates at 15k chars.
  • Dragging to select PDF text copies it; plain click still does click-to-read.
